# Harness Intelligence

HI 是面向 Windows Codex Desktop 用户的本地辅助应用，用于查看项目配置、工程指导、Skills、会话线索与用量，并在用户授权的范围内维护部分工程指导。

最新公开预览版本为 **0.2.0**。[下载 Windows x64 安装包](https://github.com/Sevenjustin21/HarnessIntelligence-Releases/releases/download/v0.2.0/Harness.Intelligence_0.2.0_x64-setup.exe) · [发行说明与校验文件](https://github.com/Sevenjustin21/HarnessIntelligence-Releases/releases/tag/v0.2.0)。

这个仓库用于安装包、更新文件、使用说明和问题反馈。HI 自有源码目前保持私有；个人和企业可按随发行附带的二进制许可免费使用 HI，并可在保留版权说明和第三方声明的条件下原样转发完整安装包。修改后再分发、另行出售该软件或使用 HI 品牌作背书须另获许可。第三方组件依各自许可证提供许可文本及相应源码获取地址，其权利不受上述 HI 自有部分条款限制。

当前发行提供 Windows x64 安装包。已实测 Windows 11 x64 且已有可用 Microsoft WebView2 Runtime 的场景。Windows 10 和完全缺失 WebView2 时的联网补装尚未完成实机验证，详情见对应发行说明。HI 已提供“设置 → 高级与关于 → 检查更新”，由用户决定何时下载和安装；推送代码本身不会触发应用升级。本版没有 Windows 发布者证书，可能出现“未知发布者”或 SmartScreen 提示，请核对官方来源与校验文件，不要关闭系统防护。

反馈问题时请提供应用版本、Windows 版本、复现步骤和经过检查的截图。请勿提交账户密钥、登录文件、完整对话或私人项目代码。
